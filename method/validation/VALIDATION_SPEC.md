# VALIDATION_SPEC — external validation before target prediction (frozen 2026-08-30)

## Constraint disclosure
The prediction lock is 2026-08-31 (deposit window closes then). Full leave-one-study-out
validation across a multi-study archive is not executable in the remaining time/budget.
This spec defines the REDUCED validation actually performed, chosen before target
prediction, with its limitations stated plainly. Everything here is frozen before any
target forecast is generated.

## Study-level separation (leakage control)
- CALIBRATION evidence (shrinkage factor 0.56): Hewitt et al. Nature archive — 70 TESS/
  replication experiments. We reuse their published coefficient; we do not refit it.
- EVALUATION study: Vlasceanu et al. 2024 (Sci Adv) climate megastudy — 11 one-shot
  text interventions, outcomes: belief (0–100), policy support (0–100), social-media
  sharing (binary), tree-planting behavior (WEPT). DISJOINT from the calibration archive
  at study level (it is in the Nature paper's *megastudy* holdout, not the archive the
  0.56 was fit on).
- Known limitation: Vlasceanu 2024 is published and certainly inside the FORECAST_MODEL's
  training data. The Nature paper found unpublished-study accuracy at least as high as
  published (r=0.90 vs 0.74–0.85), so leakage inflates estimates modestly if at all,
  but our probe still overstates true blind accuracy by an unknown margin. Documented,
  not correctable in the time available.
- The target study's own human outcomes are sealed; nothing about them is used anywhere.

## Probe 1 — Tier-3 pipeline on Vlasceanu (target protocol, blind)
- Reproduces the ACTUAL Tier-3 forecasting procedure: per-condition batched call, k=2
  independent forecasters per condition, exact same prompt skeleton as the target run
  (evidence table REDACTED of anything derived from Vlasceanu itself to avoid circular
  scoring), aggregation = median of forecasters.
- 11 interventions × 4 outcomes = 44 ATEs, in original units (pp for binary outcomes).
- Scoring targets (published facts; coarse because per-arm SI tables could not be
  digitized in time):
  a. SIGN/NULL pattern: behavior (tree planting) effects ≈ 0 or negative for all arms;
     belief/policy small positive for most arms; sharing positive and larger.
  b. BEST-ARM identity: belief → psychological distance; policy → letter to future
     generation; sharing → negative emotions (dooms-day). Metric: top-3 hit rate.
  c. MAGNITUDE band: best belief ≈ +2.3pp; best policy ≈ +2.6pp; best sharing ≈ +12pp.
     Metric: ratio of our best-arm forecast to published best (magnitude bias factor).
- DECISION RULES (frozen):
  R1. If raw (unshrunk) magnitude-bias factor > 1.3 → apply ×0.56 shrinkage to Tier-3
      and Tier-2 implied ATEs (consistent with E4). If factor in [0.7, 1.3] → NO
      shrinkage (identity). If < 0.7 → no shrinkage (never inflate). Never fit a new
      coefficient.
  R2. Rank-reconciliation pass (comparative ranking) is INCLUDED in the target Tier-3
      pipeline only if it improves the probe's Spearman ρ against the coarse targets
      (best-arm placement); else absolute forecasts stand unchanged. Fixed blend if
      included: final ATE = absolute magnitude of the forecaster median, reordered
      within outcome by the average of (absolute-rank, comparative-rank) — a fixed
      50/50 rank blend, no learned weights.
  R3. Forecaster count k for the target run: k=3 if probe shows median-of-2 within-call
      instability (range > 50% of median on >25% of cells), else k=2. (Cost-bounded.)
- Cost guard: ≤ $2 equivalent for the probe (22 calls, tools disabled, cached prompt).

## Probe 2 — Tier-1 respondent session (cost + sanity, control condition only)
- 12 synthetic respondents, whole-session single-call protocol, OUR actual instrument
  (control condition, one filler each, full scored battery, compressed CSV output).
- Checks (frozen pass criteria):
  a. schema validity ≥ 10/12 parse cleanly on first attempt;
  b. integer sliders in range; composites consistent (recomputed vs implied);
  c. dispersion sanity: across-respondent SD of trust_post in [10, 35] (human survey
     SDs on 0–100 attitude sliders are typically ~20–30; guards against collapse);
  d. baseline sanity: control-group means within ±15pp of EVIDENCE_MEMO §6 anchors for
     trust_post, belief_post, policy_general;
  e. measured cost/respondent and runtime/respondent → feeds the Tier-1 budget decision.
- No decisions about persona richness are taken from this probe (evidence already fixed:
  demographics-only personas, E1/E25/E27); it validates execution, not design.

## Probe 3 — Tier-2 baseline check (no model calls)
- Tier-2 control-cell forecasts are generated by the target pipeline later; this probe
  simply pre-registers that control cells must land within ±12pp of the §6 anchors or
  the run is flagged (not edited) and re-examined for prompt defects before lock.

## Metrics implementation
validation/score_probe.py computes: pooled Pearson, Spearman, within-outcome Pearson,
directional agreement (half credit at 0), RMSE in pp-of-range, mean signed error, and
OLS calibration slope/intercept — the same functions to be reused verbatim for any
future scoring, so the metric code itself is exercised before the lock.

## Primary-entry selection rule (frozen, external evidence + probe)
Prefer the method with best expected pooled Pearson on held-out evidence. Standing
external evidence (E1–E6): participant simulation (Tier 1) is the best-validated method
overall (r=0.85–0.90 across studies; r_adj=0.61 within megastudies) and the benchmark
scores Tier 1 on every analysis. THEREFORE: if Tier 1 is executed, Tier 1 entry =
primary. If Tier 1 is not executed (budget decision), primary = Tier 3 if probe pooled
direction+rank performance ≥ Tier-2-implied performance, else Tier 2. Tie → lower
expected RMSE (i.e., the calibrated entry). This rule is locked now, before any target
forecast exists.
